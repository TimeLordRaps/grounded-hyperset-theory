Interaction graph

Drag the background to pan and the wheel to zoom; double-click or f fits the whole graph. Drag a node to move it — it stays where you put it until you unpin. Hover a node or an edge for what it is and what the edge was read from. Click to focus; shift-click two parts to trace the shortest path between them.

Structure is laid out by the graph itself, not by anything declared: parts that all reach each other are grouped into a ring, and between rings every edge points one way down the page, so cycles are exactly and only what stays inside a ring. Disc area tracks the size of a package’s public API; stroke weight tracks how many times one part names another. Toggle an edge kind to recompute the whole structure without it.

API reference, whole family

Generated from the repositories by tools/build_family_graph.py, which reads only git-tracked files. dependency edges are declared in pyproject.toml; import edges are real Python imports; citation edges are tracked prose naming another part. A citation edge is a cross-reference, not a proof, a derivation or an implemented interface — it records only that one repository names another.

The digest above is the SHA-256 of the canonical graph payload. Every repository in the family ships the same family-graph.json; if two pages show different digests, one of them is stale.
