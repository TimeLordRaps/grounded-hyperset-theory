Interaction graph

Laid out by the structure of the graph itself, not by anything declared. Parts that all reach each other are grouped into a ring; between rings every edge points one way down the page, so cycles are exactly and only what stays inside a ring. The most-cited parts settle at the bottom. Disc area tracks the size of a package's public API and stroke weight tracks how many times one part names another.

grounded-hyperset-theory is outlined, and the edges touching it are held at full strength while the rest fade. Click any node to move that highlight — the panel beside the graph and the API index below follow, while the layout holds still. Toggle an edge kind to recompute the whole structure without it.

API reference, whole family

Generated from the repositories by tools/build_family_graph.py, which reads only git-tracked files. dependency edges are declared in pyproject.toml; import edges are real Python imports; citation edges are tracked prose naming another part. A citation edge is a cross-reference, not a proof, a derivation or an implemented interface — it records only that one repository names another.

The digest above is the SHA-256 of the canonical graph payload. Every repository in the family ships the same family-graph.json; if two pages show different digests, one of them is stale.
