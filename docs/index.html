Grounded Hyperset Theory

Accessible Pointed Graphs, non-well-founded sets, constructive membership, and formal calculi pathways.

GitHub Repository PyPI Distribution

Overview

Grounded Hyperset Theory provides a pure Python reference implementation of non-well-founded set theory under Aczel's Anti-Foundation Axiom (AFA), representing hypersets as Accessible Pointed Graphs (APGs).

Formal Calculi Pathways

  • Abstraction & Quotienting: NodePartition, quotient_apg, coarsest bisimulation refinement by iterated signature grouping, SCC DAG condensation.
  • Meta-Calculus: Rewrite systems, state-transition trajectories as APGs, confluence verification, dynamical bisimulation.
  • Hyper-Calculus: Permutation groups, APG and hyperset automorphisms, symmetry orbits, and discrete derivatives.
  • Language Calculus: Formal grammars, circular quotation trees, self-referential liar sentences, and regular expression derivatives.
  • Real Analysis Bridge: Grounded integers and rationals, Dedekind cuts (√2, golden ratio), Cauchy sequences, and Surreal numbers.

Quickstart

from grounded_hyperset_theory import (
    QuineAtom,
    EmptyHyperset,
    von_neumann_ordinal,
    AccessiblePointedGraph,
    DedekindCut,
)

# Canonical Quine Atom (Ω = {Ω})
omega = QuineAtom()
assert omega in omega

# Von Neumann Ordinals
ord3 = von_neumann_ordinal(3)
assert ord3.cardinality() == 3

# Real Analysis Bridge: Dedekind Cut for √2
cut = DedekindCut.sqrt_two()
low, high = cut.binary_search_interval(1, 2, iterations=15)
